# Development snapshot 0.3.4

`GodotIsland-0.3.4-development.zip` is an unfinished Windows development snapshot, preserved here with the source. It is not a playable first-island campaign and has not passed a fresh Melty installation test. The documentation inside the archive reflects the moment it was created; the project-level README and PROJECT_RU.md have the current status.

The archive requires a player's own installed Black & White. Melty's draft recipe provides its location at launch. The archive contains the Godot runtime, the project's own files and the credited minimp3 decoder; it does not contain original Black & White game assets. It is not a Melty publication or an approved release.

`package-0.3.4.json` records the package contents and checksum. `recipe-0.3.4-draft.json` records the draft setup that passed static checks; it has not been tested as an installation. It is kept here as development documentation and is not an active release configuration.
